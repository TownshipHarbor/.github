# Quest ports for A Township Tale

PC mods for A Township Tale, ported to the Quest. Every port leaves the original server mod as it is, so Quest and PC players share one server.

The ports are by Shadow, made with each original author's permission. The original mods, their art and their design belong to their authors.

## Install

Most ports are on the Download board in the game's main menu. To install one by hand, put the DLL from its release in the headset's Mods folder:

```
/sdcard/Android/data/com.Alta.ATownshipTale/files/MelonLoader/com.Alta.ATownshipTale/Mods/
```

Each repo's README says what the server needs and what differs from the PC version.
